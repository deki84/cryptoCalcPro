# CryptoCalc Pro

A full-stack crypto portfolio tracker built with Next.js, TypeScript and Neon PostgreSQL.

🔗 **Live Demo:** https://cryptocalc.dejan-jankovic.dev

## Features

- 📊 Real-time cryptocurrency portfolio tracking
- 🔐 Authentication via Clerk (Google & GitHub Login)
- 💾 Dual storage – database for authenticated users, localStorage for demo mode
- 📱 Responsive design with Tailwind CSS
- 🚀 Deployed on Vercel with custom domain

## Tech Stack

- **Frontend:** Next.js 15, React, TypeScript, Tailwind CSS
- **Auth:** Clerk Authentication
- **Database:** Neon PostgreSQL
- **Deployment:** Vercel

## Getting Started

1. Clone the repository
2. Install dependencies: `npm install`
3. Set up environment variables (see `.env.example`)
4. Run development server: `npm run dev`
